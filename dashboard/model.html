Machine learning / explainable by design

A model that learns who is likely to purchase.

Ecommerce Plus trains a lightweight logistic regression model in the browser. It uses funnel progress and available segment fields to estimate purchase probability.

What it predictsPurchase probability

For each user who viewed a product, the model estimates the chance of eventual purchase.

What it learns fromFunnel progress + context

Add-to-cart, checkout-start, device, traffic source, and region are converted into model features.

Why it is usefulPrioritize attention

Growth teams can focus messaging, support, or experiments on users and segments with the largest opportunity.

Important: the model is trained on the data loaded into the Overview page. Demo mode uses synthetic data; upload real company events to train on real behavior. This is a directional propensity model, not a causal forecast.
